GravitationalWaveforms.jl

A gravitational-wave waveform toolkit: frequency-domain approximants (IMRPhenomD, IMRPhenomXAS, IMRPhenomXHM, IMRPhenomXP, IMRPhenomXPHM) and time-domain post-Newtonian/ODE-integrated models (TaylorT3, ODEToy), all Float32/Float64-generic. Part of the same ecosystem as GravitationalWaveData.jl (the gwpy-equivalent data toolkit) and GravitationalWaveBayes.jl (GPU-native, Enzyme-differentiable Bayesian parameter estimation) — dependency order GravitationalWaveData <- GravitationalWaveforms <- GravitationalWaveBayes.

Where to start

  • New to the package? Start with Getting Started — generate your first frequency-domain waveform and plot it.
  • Read the Conventions page early — units (dL in Gpc, not Mpc!), the m1 >= m2 labeling convention, the t <= 0 time-domain convention, and the h ~ Ampl*exp(i*Phi) decomposition are used, unremarked, in every tutorial below.
  • Want the full function/type list? See the API Reference.
  • Coming from ripple (JAX) or lalsimulation (C)? Every model here is a direct, cross-validated port of the corresponding lalsimulation generator — the tutorials cite the matching ripple/LALSuite function or example where one exists.
